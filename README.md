\## Objetivo do software



O Restaurante Sakura é um sistema desktop desenvolvido para auxiliar no gerenciamento de um restaurante, permitindo o cadastro e gerenciamento de clientes e produtos, além do registro de pedidos.



O projeto foi desenvolvido como parte do Projeto Integrador do curso Técnico em Análise e Desenvolvimento de Sistemas.



\## Funcionalidades do sistema



\* Cadastro, alteração, consulta e exclusão de clientes.

\* Cadastro, alteração, consulta e exclusão de produtos.

\* Controle de disponibilidade dos produtos.

\* Criação de pedidos.

\* Seleção de clientes e produtos para os pedidos.

\* Cálculo automático do subtotal dos itens.

\* Cálculo do valor total do pedido.

\* Registro dos pedidos no banco de dados.

\* Registro dos itens relacionados a cada pedido.

\* Navegação entre as telas do sistema.

\* Persistência dos dados utilizando MySQL e JDBC.
